# Histone-Modification-Toolbox
Contains all processing code from the paper "A Toolbox to Quantify the Spatial Distribution of Post-translational Histone Modifications from 3D Spectrscopic SMLM Images". This code is intended for use on multicolor images of nuclear proteins such as histone modifications or RNA polymerase

**Full documentation: [DOCUMENTATION.md](DOCUMENTATION.md).** It contains the original
step-by-step instructions that used to be here (verbatim, under
[Original instructions](DOCUMENTATION.md#original-instructions)), plus what each step does, the
files passed between steps, requirements, missing inputs and how to restore them from git, and
known issues. Each folder (`Initialization/`, `Analysis/`, `Simulation/`, `demo/`) also has a
README describing every script in it.
