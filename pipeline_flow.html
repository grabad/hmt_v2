Nanodomain Pipeline Flow

Every calculation from the RainbowSTORM exports to the condition statistics, as run by python drivers/run_all.py. Each step skips cells whose outputs already exist unless it is run with --overwrite.

  1. 01Preprocess each cell
  2. 02Calibrate DBSCAN on a simulated nucleus (2a–2g)
  3. 03Cluster every cell
  4. 04Radial profiles and SNCR
  5. 05Pool cells, compare conditions

Click a box to see how it is computed. Its inputs light up in blue and the boxes that use it in orange. Red IDs such as A2 are weak points written up on the Nanodomain Calibration Pipeline page, which this chart accompanies.
